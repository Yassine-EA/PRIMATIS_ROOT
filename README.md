# PRIMATIS

PRIMATIS est une application web de gestion de bibliothèque réalisée dans le cadre d’un travail de fin d’études en informatique de gestion.

Le livrable contient :

- `primatis-api/` : backend Java / Spring Boot ;
- `primatis-web/` : frontend Angular ;
- `database/primatis_demo.dump` : base de données de démonstration PostgreSQL ;
- `docs/demo/DEMO-CREDENTIALS.md` : comptes de démonstration.
